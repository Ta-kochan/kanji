# ChatGPT 画像生成プロンプト集

ChatGPT の画像生成でアプリ用の画像を作るためのプロンプトです。
プロンプトをそのまま ChatGPT に貼り付けて送ると、画像が1枚できます。できた画像はダウンロードして `public/images/` に、下に書いたファイル名で保存してください。置いた画像は自動で表示されます。

## 作るときのコツ

- **白柴は全部1つのチャットで作る**：同じチャットの中で「さっきの柴犬で」と頼むと、見た目がそろいやすくなります。
- **背景も1つのチャットにまとめる**：絵のタッチがそろいます。白柴とは別のチャットにしてください。
- **白柴と桜の枝は背景を透明にする**：プロンプトに「背景は透明（PNG）」と入れてあります。もし白い背景で出てきたら「背景を透明にしてください」と追加で頼んでください。
- **背景は横長で作る**：ChatGPT が作れる横長は3:2です。画面に合わせて自動で切り取るので、そのままで大丈夫です。
- 気に入らなければ「もう少し落ち着いた色に」「中央をすっきりさせて」など、言葉で直しを頼めます。

## 1. 背景（1つ目のチャット）

### 最初に送る1通：絵のタッチを決める

```
これから日本アニメ調の背景イラストを何枚か作ってもらいます。全部に共通するルールは次の通りです。
・手描きの日本アニメ映画の背景美術のようなタッチ。水彩とガッシュの柔らかい質感
・落ち着いたパステル寄りの色合い。やわらかい光。静かで懐かしい雰囲気
・人物、文字、ロゴ、透かしは入れない
・横長（3:2）
・画面中央に文字のカードを重ねるので、中央は細かく描き込みすぎない
了解したら、1枚目として次の絵を作ってください。

夕暮れの小さな神社へと続く石畳の道。赤い鳥居と石灯籠、数本の桜の木。遠くに重なる山々。ラベンダーと藍色の空にやわらかい雲。
```

→ 保存名：`bg-main.png`

## 2. 白柴キャラクター（2つ目のチャット）

### 最初に送る1通：キャラを決める

```
アプリのマスコットキャラクターを作ってください。
・白い柴犬。ちびキャラのアニメ調で、丸くてふわふわの体
・クリームがかった白い毛、首に小さな朱色のスカーフ
・大きくて親しみやすい目。やわらかいアニメ塗り、すっきりした線
・全身、正面向き
・背景は透明（PNG）。影や床も描かない
・正方形
```

気に入るまで「もっと丸く」「目を大きく」などと直してもらい、決まったら次に進みます。

## 3. 小道具（どちらのチャットでも可）

**和紙（ハンコの下の紙）**：`washi.png`

```
伝統的な日本の和紙のテクスチャ画像を作ってください。生成りの白で、繊維がうっすら見える。真上から見た平らな紙で、均一な明るさ。上下左右につなげて並べても継ぎ目が目立たない模様。正方形。
```

**桜の枝（カード左上の飾り）**：`deco-branch.png`

```
桜の枝を1本描いてください。ピンクの花が数輪。アニメ調のイラストで、やわらかいパステルカラー。枝の根元が左下、花が右上に向かって伸びる向き。背景は透明（PNG）、横長（3:2）。
```
